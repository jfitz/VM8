Redirection

Handled inside kernel
Requires 2 FCBs and 2 buffers of 128 bytes each

Calls to CONIN, CONOUT, and CONOUT_S first check for redirection, write to buffer.

Requires system calls for START, EXIT. START specifies file names for stdin and stdout. EXIT closes the FCBs.

Requires shell that can parse '<' and '>' for redirection, and invoke START.
