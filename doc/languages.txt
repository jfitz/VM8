File formats
source: text
object: dot notation with executable, readonly?, writable?, symbols, references, instruction-offsets
lib: object+
relocatable: dot notation with executable, readonly?, writable?
fixed: dot notation with executable, readonly?, writable?
EXE: binary with metadata
COM: binary, no metadata
ABS: binary, no metadata

Tools

asm: source -> object, list
dasm: object -> source
linker: object+ lib* -> relocatable
loader: relocatable -> fixed
fixed_to_exe: fixed -> EXE (for CP/M or HDOS)
fixed_to_com: fixed -> COM (for CP/M)
fixed_to_abs: fixed -> ABS (for HDOS)

Possible languages

libraries
- written in C
- lib16m: 16-bit math
- lib24m: 24-bit math
- lib32m: 32-bit math

Assembly language
- 8080

Calling conventions:
- Fortran:
   values left-to-right
   last value is number of params
   then return address
   callee cleans stack
   no recursion
- C:
   values right-to-left
   last value is number of params
   then return address
   caller cleans stack
   recursion allowed

BB (.bb)
- similar to C
- ints and pointers to int, possibly refs to int
- no user-defined functions
- no arrays
- no preprocessor
- functions must be defined before use (like Pascal)
- no files
- no structs
- expressions only in assignment
- expressions in RPN

C (.c)
- use math libs
- krc: K&R version
- ansic: ANSI version (perhaps not complete ANSI)
- cwc: C with classes (structs with functions) no inheritance, no templates
- sc: simplified C
